# Template Mobile Calculator — JSTUDIO App Factory

Template base para geração de microapps de cálculo (ex: Calculadora de Lucro Shopee, Média Final, Quanto Posso Gastar?).

## DNA do Produto
- **Stack**: React 19 + Tailwind 4 + Vite + Capacitor 8
- **Target SDK**: 36 (Android 16 Google Play)
- **Pacotes Compartilhados**: `@jstudio/ui`, `@jstudio/storage`, `@jstudio/analytics`, `@jstudio/ads`, `@jstudio/consent`, `@jstudio/notifications`
